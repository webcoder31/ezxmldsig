# Demonstration keys: public, never use them elsewhere

**The private keys of this directory are public.** They are published with the source code of ezxmldsig, so that the examples work out of the box. Anyone who has the library has them:

* `sign.key.pem` (and its password, `signKeyPassword`, written in the examples) lets anyone sign tokens that a receiver trusting `intermediate.cert.pem` and `root.cert.pem` accepts;
* `crypt.key.pem` (and its password, `cryptKeyPassword`) lets anyone decrypt the tokens encrypted with `crypt.cert.pem`.

Use these files for the examples only. Never use them, nor trust these CA certificates, in an application, a test environment reachable by others, or a production system: generate your own keys and certificates, and keep the private keys out of any repository.

The files are generated by `bin/gen-test-certs --examples`:

| File | Content |
|---|---|
| `root.cert.pem` | Root CA certificate (trust anchor of `examples/parse-xml-token.php`) |
| `intermediate.cert.pem` | Intermediate CA certificate, issued by the root (trust anchor too) |
| `sign.cert.pem`, `sign.key.pem` | Signing certificate issued by the intermediate CA, and its private key |
| `crypt.cert.pem`, `crypt.key.pem` | Encryption certificate issued by the intermediate CA, and its private key |
