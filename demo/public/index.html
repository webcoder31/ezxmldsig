ezxmldsig

XML Digital Signature · enveloping tokens · PHP

Sign it, read it, verify it.
Then try to break it.

Every token on this page is created and analyzed by the real ezxmldsig library, running in PHP behind this page. Read each block of the signature, follow the receiver's checks one by one, and replay the attacks that version 1.0.0 refuses. The same tokens can be created and verified in Node.js with @webcoder31/ezxmldsig.

The keys of demo/certs/ are public: they are published with the library. Never use them, or trust their CA, outside this demo.
