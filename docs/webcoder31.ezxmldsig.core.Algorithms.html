    Class webcoder31\ezxmldsig\core\Algorithms

    The algorithms of XML Signature, named by their URIs, as xmlseclibs names them: canonicalization, digest and signature. The tokens and the seals take their identifiers from here; which ones each accepts is its own policy. XMLDSigToken has the same constants, with the algorithms of XML Encryption.
