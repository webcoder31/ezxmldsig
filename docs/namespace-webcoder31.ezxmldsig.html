    X509Cert

    Analyze an X.509 certificate. The X509Cert class provides a set of convenient methods for extracting essential information contained in an X.509 certificate and for performing some useful checkings. Every cryptographic check (signature of the certificate, chain of trust, validity dates) is performed by OpenSSL. This class is used internaly by the XMLDSigToken class.
    XMLDSigToken

    Build or analyze an XML token. An XML token is an enveloping XML Digital Signature (cf. RFC 3275) containing signed and timestamped user data. These data may also be encrypted. In this case we talk about Secure XML token. This class uses the following default algorithms to operate: - Algorithm used to canonalize data before signing is: http://www.w3.org/TR/2001/REC-xml-c14n-20010315. - Algorithm used to generate the signature is: http://www.w3.org/2001/04/xmldsig-more#rsa-sha256. - Algorithm used to compute the hash of token data is: http://www.w3.org/2001/04/xmlenc#sha256. - Algorithm used to encode data's values is: Base64. The analysis expects these algorithms unless its options name others (see __construct()), and it requires a trust anchor: the CA certificates and/or the pinned certificate the signing certificate is verified against.
