# Single sign-on demo keys: public, never use them elsewhere

**The private keys of this directory are public.** They are published with the source code of ezxmldsig, so that the single sign-on demo works out of the box: anyone who has the library can decrypt the tokens encrypted with these certificates.

Use these files for the demo only. Never use them in an application, a test environment reachable by others, or a production system: generate your own keys and certificates, and keep the private keys out of any repository.

| File | Content |
|---|---|
| `mail.crypt.cert.pem`, `mail.crypt.key.pem` | Encryption certificate of the application mail, signed by its own key, and its private key (no password) |
| `crm.crypt.cert.pem`, `crm.crypt.key.pem` | Encryption certificate of the application crm, signed by its own key, and its private key (no password) |

The library does not verify the chain of an encryption certificate: the issuer encrypts for the certificate it is given. The signing certificate of idp and the trust anchor of the applications come from `demo/certs/` (see `demo/certs/README.md`).

The files are generated by `bin/gen-test-certs --demo-sso`. Every certificate is valid for 10 years from its generation.
